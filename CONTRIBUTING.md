# Contributing

The contributor guide, with the inclusion criteria and the entry format, lives at [docs/contributing.md](docs/contributing.md). It is also on the website at <https://atlas-bear.github.io/recommended-reading/contributing/>.

The short version: propose a title through the [issue form](https://github.com/atlas-bear/recommended-reading/issues/new/choose) or open a pull request that adds a block to `data/library.yml`. `README.md`, the list pages in `docs/` and the files in `exports/` are generated from that YAML by `python scripts/build.py`, so please do not edit them by hand.
